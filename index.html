Положение в таблице Менделеева

Водород — первый элемент периодической системы, его атомный номер — 1, относительная атомная масса Ar ≈ 1,008. Занимает уникальное, двойственное положение в таблице:

I группа (главная подгруппа)

Формально близок к щелочным металлам: один валентный электрон, может проявлять степень окисления +1 и отдавать электрон.

VII группа (главная подгруппа)

Близок к галогенам: до завершения внешнего уровня не хватает одного электрона, поэтому может принимать его, проявляя степень окисления −1.

Вне групп

Часто водород выносят отдельно (в левом верхнем углу), поскольку его свойства не совпадают полностью ни с металлами, ни с галогенами.

Водород — самый распространённый элемент во Вселенной (≈ 75 % по массе), на Земле в свободном виде встречается редко: в основном в составе воды, углеводородов, минералов и живых организмов.

Факт. Водород — единственный элемент, у которого изотопы имеют собственные имена и символы: протий 1H (обычный), дейтерий 2H (D), тритий 3H (T, радиоактивен). Тяжёлая вода D₂O используется в ядерных реакторах.

Электронная конфигурация

Атом водорода содержит один электрон, который располагается на 1s-орбитали:

1s¹

  • Водород — s-элемент, единственный не заполненный до конца 1s-подуровень.
  • Тип химической связи в простом веществе H₂ — ковалентная неполярная, связь одинарная (σ).
  • Энергия связи H–H велика — ≈ 436 кДж/моль, поэтому молекула H₂ термически устойчива.
  • В соединениях водород обычно образует одну ковалентную связь, валентность его равна I.
Факт. Водород — самая лёгкая молекула во Вселенной. Молекулы H₂ движутся настолько быстро, что гравитация Земли не может удержать их, поэтому в атмосфере свободного водорода почти нет — он улетучивается в космос.

Характерные степени окисления и валентность

Степень окисленияПримеры соединенийРоль водорода
0 H₂ — простое вещество —
+1 HCl, H₂O, H₂S, H₂SO₄, HNO₃, CH₄ Восстановитель
−1 NaH, CaH₂, LiH, KH (гидриды металлов) Окислитель

Чаще всего водород проявляет степень окисления +1, поскольку отдаёт единственный электрон. Отрицательная степень окисления возможна только в соединениях с металлами, которые сильнее притягивают электрон.

Температура кипения

Диффузия

Обладает высокой способностью проникать в металлы

Молекула H₂ — неполярная и очень маленькая, поэтому газ почти не растворяется в воде. Это используют, например, для сбора водорода методом вытеснения воды.
Факт. Водород — единственный газ, который в быту легко взрывается при малейшей искре («гремучий газ» — смесь H₂ и O₂). Именно поэтому в дирижаблях его заменили на гелий после катастрофы «Гинденбурга» в 1937 году.

Химические свойства ЕГЭ

Водород — восстановитель в реакциях с неметаллами и большинством оксидов металлов, и только окислитель в реакциях с активными металлами.

1. Реакции с неметаллами (водород — восстановитель)

2H₂ + O₂ → 2H₂O (поджигание, взрыв)
H₂ + Cl₂ → 2HCl (свет, взрыв)
N₂ + 3H₂ ⇄ 2NH₃ (t, p, кат. Fe)
H₂ + S ⇄ H₂S (при нагревании)
2H₂ + C ⇄ CH₄ (t, кат. Ni)

2. Восстановление металлов из оксидов (водород — восстановитель)

CuO + H₂ → Cu + H₂O (при нагревании)
Fe₂O₃ + 3H₂ → 2Fe + 3H₂O (при нагревании)
WO₃ + 3H₂ → W + 3H₂O (t, восстановление тугоплавких металлов)
Восстановление оксидов используют для металлов, стоящих в ряду напряжений правее Zn (Cu, Fe, W, Mo и др.). Для активных металлов (Na, K, Mg, Al) водородное восстановление оксидов не применяют.

3. Реакции с активными металлами (водород — окислитель)

2Na + H₂ → 2NaH (при нагревании)
Ca + H₂ → CaH₂ (t)

Гидриды активных металлов разлагаются водой:

NaH + H₂O → NaOH + H₂↑
CaH₂ + 2H₂O → Ca(OH)₂ + 2H₂↑

4. Реакции с органическими веществами

C₂H₄ + H₂ → C₂H₆ (t, кат. Ni или Pt)
C₂H₂ + 2H₂ → C₂H₆ (гидрирование)
Факт. Реакция H₂ + Cl₂ на свету идёт по цепному механизму: одна квант света запускает образование тысяч молекул HCl. Это классический пример цепной реакции в ЕГЭ.

Способы получения ЕГЭ

В лаборатории

1. Взаимодействие металлов с кислотами (в аппарате Киппа):

Zn + 2HCl → ZnCl₂ + H₂↑
Fe + H₂SO₄ (разб.) → FeSO₄ + H₂↑
Металл должен стоять в ряду напряжений до водорода. Реакцию не проводят с HNO₃ любой концентрации и с концентрированной H₂SO₄ — выделяется не H₂, а другие газы.

2. Взаимодействие активных металлов с водой:

2Na + 2H₂O → 2NaOH + H₂↑
Ca + 2H₂O → Ca(OH)₂ + H₂↑

3. Взаимодействие алюминия и цинка со щелочами:

2Al + 2NaOH + 6H₂O → 2Na[Al(OH)₄] + 3H₂↑
Zn + 2KOH + 2H₂O → K₂[Zn(OH)₄] + H₂↑

В промышленности

1. Паровая конверсия метана (основной метод):

CH₄ + H₂O ⇄ CO + 3H₂ (t, кат. Ni)

2. Пиролиз метана (термическое разложение):

CH₄ → C + 2H₂ (t ≈ 1200 °C)

3. Конверсия угля с водяным паром:

C + H₂O → CO + H₂ (t)

4. Электролиз воды (энергозатратный):

2H₂O → 2H₂↑ + O₂↑ (электрический ток)
Факт. В 2023 году мировой спрос на водород превысил 95 млн тонн в год. При этом почти весь он до сих пор получается из ископаемого топлива — «зелёный» водород (электролиз на возобновляемой энергии) составляет лишь несколько процентов.

Вывод

Водород — уникальный элемент с двойственным положением в периодической системе и двойственной окислительно-восстановительной природой. В подавляющем большинстве реакций он выступает восстановителем, но с активными металлами образует гидриды, проявляя себя как окислитель.

Как простое вещество водород — самое лёгкое и самое распространённое во Вселенной. Как химическое сырьё он незаменим для синтеза аммиака (процесс Габера), получения соляной кислоты, метанола, гидрирования жиров и нефтепродуктов. В металлургии он служит восстановителем при получении тугоплавких металлов.

В перспективе водород рассматривается как экологически чистое топливо: при его сгорании образуется только вода. Именно поэтому водородная энергетика — одно из ключевых направлений современной науки и техники.

Главное для ЕГЭ: помнить про восстановительные свойства (с неметаллами и оксидами металлов) и окислительные свойства (с активными металлами), а также три ключевых лабораторных способа получения: металл + кислота, металл + вода, металл + щёлочь.
